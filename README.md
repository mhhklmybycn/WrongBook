# 错题本 · 智能错题库

一款**零构建、纯前端**的本地化错题管理工具：拍照导入错题，AI 识图自动整理出题目、答案、解析与知识点，确认后归档进个人错题文库。所有数据保存在本机浏览器中，不依赖任何后端服务。

## 功能特性

### 导入错题
- 多选上传错题照片，支持预览、**裁剪、旋转**（内置图片编辑器）
- **AI 识图整理**：图片直传你配置的多模态大模型，自动输出学科、难度、题目正文、参考答案、解析、知识点（固定教研提示词，不编造图片中没有的内容），识别过程流式显示、可随时中断
- 识别结果可手动修改确认后再归档
- **AI 生成答案/解析**：对缺少答案或解析的错题，一键流式生成并拆分填入

### 错题文库
- 多维整理：学科（语文 / 数学 / 英语 / 物理 / 化学 / 生物 / 政治 / 历史 / 地理 / **计算机** / 其他）、难度 1–5 星、标签、知识点
- 关键词搜索 + 状态管理（待学习 / 复习中 / 已掌握）
- 详情查看：图片灯箱放大、答案/解析分区展示
- 支持编辑、删除

### API 设置
- 兼容 **OpenAI Chat Completions 协议**的任意服务商，内置预设：DeepSeek、智谱 GLM、通义千问、Kimi、豆包（火山方舟）、OpenAI、SiliconFlow、自定义中转
- 可配置温度、最大 Token、超时时间，一键**测试连接**（显示模型与响应耗时）
- 密钥仅保存在**本机浏览器 localStorage**，不写入任何文件

### 数据管理
- 本地存储：IndexedDB（题目与图片一体保存）
- **备份 / 恢复**：导出 JSON（图片以 base64 内嵌），可完整还原
- **导出 Excel**（.xlsx）与 **PDF**（调起浏览器打印，选择"另存为 PDF"）

### 体验细节
- 深色 / 浅色 / 跟随系统三种主题
- 响应式布局，桌面与手机浏览器均可使用
- 第三方库（如 SheetJS）在首次使用时按需加载，网络受限时优雅降级

## 快速开始

无需安装、无需构建：

1. 下载或克隆本项目
2. 直接双击打开 `index.html` 即可使用

> 若浏览器对 `file://` 有功能限制，也可用任意静态服务器运行，例如：
>
> ```bash
> # Python
> python -m http.server 8080
> # 或 Node.js
> npx serve .
> ```
> 然后访问 `http://localhost:8080`

### 配置 AI 接口

1. 进入「API 设置」，选择服务商预设（或选"自定义"填写任意 OpenAI 兼容中转地址）
2. 填写 Base URL、API Key、模型名称，点击「测试连接」确认可用
3. **注意**：「AI 识图整理」需要模型支持**图像输入**（视觉模型）；纯文本模型只能使用「生成答案解析」功能

## 隐私说明

- 所有错题数据（含图片）仅存储在**你自己的浏览器**中，应用不含任何上报、统计代码
- 仅当你主动使用 AI 识别 / 生成功能时，相关文字与图片才会发送到**你自己配置的** API 服务商
- 清除浏览器数据会清空错题库，请定期使用「备份」功能导出 JSON

## 项目结构

```
错题库/
├── index.html        # 入口页面（侧边导航 + 视图容器 + 全局浮层）
├── styles.css        # 全部样式（含深色主题、移动端适配）

    ├── db.js         # IndexedDB 封装 + 按需动态脚本加载器
    ├── api.js        # 大模型 API 配置与调用（SSE 流式、多模态、中断）
    ├── editor.js     # 图片裁剪 / 旋转编辑器
    ├── exporter.js   # 备份 / 恢复 / Excel / PDF 导出
    └── app.js        # 应用主体（路由、四大视图、导入流水线、状态管理）
```

## 技术要点

- **零构建**：经典 `<script>` 加载，无打包器、无框架依赖，`file://` 协议下可直接运行
- **IndexedDB** 本地持久化，图片以 Blob 形式内嵌于错题记录
- **SSE 流式解析**：支持生成过程实时显示与 AbortController 中断
- **多模态识图**：图片转 base64 以 `image_url` 消息直传视觉模型，模型返回结构化 JSON 后容错提取
- **按需加载**：第三方库仅在首次使用对应功能时注入，幂等且失败可重试

## 浏览器要求

现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本），需支持 IndexedDB、Fetch Streams、CSS 变量。移动端浏览器亦可正常使用。
